# Berkas gambar karya

Taruh gambar di folder ini, misalnya `poster-kelas-x.jpg`, lalu pada formulir Karya Siswa isi `assets/karya/poster-kelas-x.jpg`. Unggah berkas tersebut ke repository GitHub Pages bersama aplikasi.

`contoh-poster.svg` adalah ilustrasi contoh buatan untuk mencoba tampilan, bukan karya siswa nyata. Tidak ada baris galeri yang otomatis dimasukkan ke Spreadsheet.
